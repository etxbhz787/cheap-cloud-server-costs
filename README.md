## 首购便宜不等于用得便宜：把三年的账算清楚

判断真实成本，只用一个公式：打算用的年数 × 续费后的年价。很多比价文章只看首购价，这是最大的误区。

## 便宜云服务器的五个常见坑

1. **带宽缩水**。低价款常只给 1Mbps，打开网页都费劲；大厂低价款甚至不含公网 IP，带宽要另花钱买。下单前看清带宽是否独享、具体给多少。
2. **配置太低**。内存小、CPU 弱，装个 WordPress 都可能卡。想清楚要跑什么，再决定加不加钱。
3. **没有独立公网 IP**。几块钱的月付机不少是 NAT 方案，只有映射端口。做内网穿透凑合能用，要建站基本没戏。
4. **售后缺位**。超低价商家的客服响应可能以天计，甚至没人理。买之前把“出了问题自己能不能解决”想清楚。
5. **跑路风险**。年付一年就是预付一年。判断一家低价商家靠不靠谱，最简单的指标是成立年限和社区讨论的存续时间。RackNerd 2019 年成立、运营多年，算这一档里的老面孔；开业半年、名字都没听过的新商家，谨慎年付。
